## 2. Motion Graphics & Cinematic Overlay Reference

1. **Smart Calendar Timeline Transition:**
   - Referensi animasi rotasi kalender digital tanggal demi tanggal di layar ponsel. Saat menyentuh tanggal tertentu (misal: "26 Oktober - Hari Jadi Sumenep"), layar meledak halus menjadi transisi video drone kembang api di atas Keraton Sumenep.
2. **Interactive Venue GPS Wayfinding:**
   - Tampilan grafis garis rute peta digital 3D dari posisi pengguna di Alun-Alun Adipura menuju gerbang utama Labang Mesem atau area stan kuliner Kaldu Kokot.
3. **Smart Notification Push Alert:**
   - Pop-up notifikasi elegan di bagian atas layar: *"Festival Musik Tong-Tong dimulai dalam 15 menit. Tunjukkan QR Pass Anda di Gate A."*
4. **Cinematic Split-Screen:**
   - Sisi kiri layar menampilkan grafik interaktif keterisian venue / reservasi tiket di web SEP, sementara sisi kanan menampilkan rekaman real-time antusiasme penonton di lokasi acara.
