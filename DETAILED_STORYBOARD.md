# SEP — DETAILED STORYBOARD
## Smart Event Sumenep — “Setelah Lampu Panggung Padam”

**Format:** 16:9 cinematic documentary + technology  
**Target durasi:** ±2:20  
**Narrative spine:** 100+ event → pertanyaan → data → analisis → decision support → event berikutnya  
**Visual ratio:** ±70% Sumenep/people/event, ±30% technology/UI/data  
**Narrator:** satu-satunya karakter konsisten; tidak ada protagonist utama.  
**Production rule:** gunakan footage/aset nyata untuk identitas Sumenep; gunakan Veo hanya untuk aksi/temporal footage yang belum tersedia; gunakan motion graphics untuk data dan UI.

# EDITING RULES

- Jangan membuat video terasa seperti demo aplikasi dari awal sampai akhir.
- Identitas Sumenep harus dominan sebelum teknologi diperkenalkan.
- Scene 03–04 harus terasa lebih hening agar masalah terasa tanpa perlu “menggurui”.
- SEP reveal harus menjadi titik balik visual.
- Data animation jangan terlalu ramai; setiap angka harus punya fungsi.
- Hindari klaim bahwa AI “menentukan anggaran”. Gunakan istilah decision support / bahan pertimbangan.
- Hindari angka hasil analisis yang belum benar-benar tersedia.
- Untuk angka 110, tampilkan konteks KALENDER EVENT 2026 bila diperlukan.
- Jangan menggunakan wajah publik/tokoh tertentu sebagai karakter utama.
- Jangan menambahkan logo palsu pada footage generatif.
- Ending harus kembali ke manusia, event, dan Sumenep — bukan berhenti di dashboard.
