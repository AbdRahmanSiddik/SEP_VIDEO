# SEP_VIDEO — VISUAL ASSET REFERENCE LIBRARY
## Project: SEP — Smart Event Sumenep
### Production Reference Library for Cinematic Video

Direktori ini berisi pustaka referensi visual autentik (foto resolusi tinggi, rekaman dokumentasi resmi, UI vector mockups, dan metadata lengkap) yang ditujukan untuk tim produksi video sinematik **SEP — Smart Event Sumenep**.

---

## Struktur Direktori

```text
SEP_VIDEO/
├── 01_LANDMARK/              # 28+ Aset (Keraton, Labang Mesem, Masjid Jamik, Asta Tinggi, Taman Sare, Kalianget)
├── 02_EVENTS/                # 19+ Aset (Musik Tong-Tong, Kerapan Sapi, Sapi Sonok, Saronen, Muang Sangkal, dll.)
├── 03_ECONOMY/               # 12+ Aset (Batik Canteng Koneng, Ukir Karduluk, Keris Aeng Tong-tong, Kaldu Kokot, UMKM)

├── 05_SUMENEP_ENVIRONMENT/   # 12+ Aset (Skyline kota, Alun-Alun Adipura, Pantai Slopeng, Pantai Lombang)
├── 06_TECH_REFERENCE/        # Vector UI mockups (Mobile QR Scanner, Dynamic Timeline, Event Check-in)
├── 07_SEP_WEBSITE/           # Desktop & Mobile Web mockups (Hero portal, Event discovery, E-Ticketing)
└── 08_LICENSE_SOURCE/        # Matriks lisensi lengkap, panduan atribusi resmi, dan database JSON
```

## Standar Metadata Aset

Setiap aset dalam pustaka ini memiliki rekaman data standar:
1. **Nama File:** Format penamaan baku industri video (`KATEGORI_LOKASI_NOMOR_DESKRIPSI.ext`).
2. **Kategori:** Penempatan babak/tema dalam alur produksi.
3. **Lokasi / Event:** Nama objek riil dan koordinat geografis di Kabupaten Sumenep.
4. **Tipe Shot & Waktu:** Sudut kamera (AERIAL / WIDE / MEDIUM / CLOSE-UP / DETAIL) dan pencahayaan (Siang, Golden Hour, Malam).
5. **URL Sumber:** Pranala asli repositori terpercaya (Wikimedia Commons, Pemkab Sumenep, Kemendikbud, Kemenparekraf).
6. **Creator / Fotografer:** Identitas pemilik karya asli.
7. **Lisensi / Hak Cipta:** CC0 1.0, CC BY-SA 4.0, CC BY 3.0, Public Domain.
8. **Tanggal Akses:** 22 September 2026.
9. **Catatan Penggunaan:** Panduan teknis pengambilan gambar, pencahayaan, pergerakan kamera, dan relevansi narasi video SEP.
